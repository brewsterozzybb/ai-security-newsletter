## Breaking News

### **Flowise AI Agent Builder Under Active CVSS 10.0 RCE Exploitation**

A maximum-severity code injection vulnerability in Flowise, a popular open-source AI agent orchestrator, remains under active exploitation today. The flaw, tracked as **CVE-2025-59528**, stems from the `CustomMCP` node which fails to sanitize user-provided configuration strings before executing them in a Node.js runtime. Security researchers at VulnCheck and BleepingComputer reported on April 7th that attackers are targeting over 12,000 internet-exposed instances to gain full machine compromise.

Key findings:
- **CVSS 10.0** — Maximum severity due to unauthenticated remote code execution.
- **Node.js Exploit Surface** — Attackers bypass sandbox restrictions via the Model Context Protocol (MCP) implementation.
- **Widespread Exposure** — Scans show thousands of instances vulnerable to a single-request exploit.

> "The internet-facing attack surface of 12,000+ instances makes the active scanning and exploitation attempts serious, as attackers have plenty of targets to opportunistically exploit." — Caitlin Condon, VulnCheck.

**Immediate actions:**
- Immediately upgrade Flowise instances to version 3.0.6 or later.
- Review and restrict network access to Flowise dashboards; do not leave agent builders exposed to the public internet without strong authentication.
- Audit any custom MCP nodes for unsanitized JavaScript execution patterns.

## Technical Deep Dives

### **Anthropic Unveils Project Glasswing to Secure AI Development**

Anthropic has officially launched **Project Glasswing**, a new security initiative focused on securing critical software infrastructure for the AI era. Disclosed alongside the "Claude Mythos Preview" system card on April 7-8, the project aims to bridge the gap between autonomous agent capabilities and software supply chain integrity. It introduces a framework for verifiable agentic actions, addressing the very types of "human error" vulnerabilities that led to the inadvertent release of Claude Code internal source code earlier this week.

Key findings:
- **Verifiable Execution** — A protocol for agents to provide cryptographic proof of policy compliance.
- **Glasswing Guardrails** — A shift away from "vibe-based" deny rules toward formal verification of shell commands.
- **System Card Insights** — The Mythos Preview specifically hardens against the "Efficiency Trap" where security checks were previously truncated to save tokens.

**Immediate actions:**
- Review the Claude Mythos Preview System Card for updated guidance on agent permissions.
- Consider participating in the Glasswing beta if your organization runs high-privilege autonomous agents.
- Audit internal "human in the loop" processes to prevent accidental source leaks similar to the recent Claude Code incident.

## Five Things to Take Into the Rest of the Day

1. **The "Custom Node" is your weakest link.** The Flowise RCE highlights a recurring pattern: standard nodes are hardened, but "Custom MCP" or "JavaScript" nodes are wide open. If you allow users to define custom logic within an AI orchestrator, you have essentially deployed a remote shell.
2. **Project Glasswing is the signal, not the noise.** Anthropic's pivot toward "securing critical software" suggests the industry is realizing that the "efficiency-first" approach is unsustainable. Expect more vendors to follow with "verifiable" agentic frameworks.
3. **API bypasses are the primary threat vector for 2026.** The Fortinet zero-day confirms that attackers are targeting the pre-authentication API layer. Ensure your AI agents aren't "hallucinating" security by assuming an API endpoint is safe just because it's undocumented.
4. **Local-first is the only true isolation.** The surge in popularity for projects like Immich and Veracrypt, coupled with corporate distrust of cloud providers, signals a mass migration of sensitive data to local, air-gapped silicon.
5. **S3-as-a-filesystem is a trap.** Amazon's "S3 Files" feature makes it too easy for an AI agent with a "Filesystem MCP" to recursively read (and leak) entire cloud buckets. Restrict these mounts to specific, read-only paths today.
