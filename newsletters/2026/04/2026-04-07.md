## Breaking News

### **Flowise AI Agent Builder Under Active CVSS 10.0 RCE Exploitation**

A maximum-severity code injection vulnerability in Flowise, a popular open-source AI agent orchestrator, has come under active exploitation. The flaw, tracked as **CVE-2025-59528**, stems from the `CustomMCP` node which fails to sanitize user-provided configuration strings before executing them in a full Node.js runtime. Security researchers at VulnCheck have observed exploitation attempts originating from persistent single-source IPs, targeting over 12,000 internet-exposed instances.

Key findings:
- **CVSS 10.0** — Maximum severity due to unauthenticated remote code execution.
- **Node.js Exploit Surface** — Attackers gain access to `child_process` and `fs` modules, enabling full machine compromise.
- **Protocol Poisoning** — The vulnerability specifically targets the Model Context Protocol (MCP) implementation within the builder.

> "The internet-facing attack surface of 12,000+ instances makes the active scanning and exploitation attempts serious, as attackers have plenty of targets to opportunistically exploit." — Caitlin Condon, VulnCheck.

**Immediate actions:**
- Immediately upgrade Flowise instances to version 3.0.6 or later.
- Review and restrict network access to Flowise dashboards; do not leave agent builders exposed to the public internet without strong authentication.
- Audit any custom MCP nodes or configurations for similar unsanitized JavaScript execution patterns.

### **Fortinet Patches Zero-Day API Bypass in FortiClient EMS**

Fortinet has released emergency out-of-band patches for **CVE-2026-35616**, a critical API authentication bypass in FortiClient EMS. The vulnerability allows an unauthenticated remote attacker to execute unauthorized code or commands via crafted API requests. CISA has already added the flaw to its Known Exploited Vulnerabilities (KEV) catalog following reports of zero-day use in the wild starting as early as March 31, 2026.

Key findings:
- **CVSS 9.1** — Critical impact on endpoint management infrastructure.
- **Zero-Day Status** — Exploitation was observed before public disclosure and patches were available.
- **API Surface Risk** — The flaw targets improper access control [CWE-284] in the pre-authentication API layer.

**Immediate actions:**
- Apply the hotfix for FortiClient EMS 7.4.5 and 7.4.6 immediately.
- Federal agencies must comply with the CISA KEV deadline of April 9, 2026.
- Check logs for unauthorized API calls to FortiClient EMS management interfaces from external IPs.

## Technical Deep Dives

### **The Rise of 'Vibe Security' Debt: Quantifying AI-Generated Vulnerabilities**

New research from Georgia Tech’s 'Vibe Security Radar' project reveals a staggering 583% increase in AI-introduced CVEs over the last three months. Researchers tracked 35 confirmed vulnerabilities in March 2026 alone that were directly traceable to AI coding tools like Claude Code and GitHub Copilot. The team uses automated agents to trace Git history and identify the "bot signatures" or coding patterns characteristic of machine-generated commits.

Key findings:
- **Exponential Growth** — AI-introduced flaws rose from 6 in January to 35 in March.
- **Signature Stripping** — While Claude Code accounts for many reported flaws due to its co-author tags, researchers estimate 5-10x more flaws are hidden in projects where AI metadata has been stripped.
- **OpenClaw Sensitivity** — The project notes that OpenClaw itself contains over 300 advisories, with significant portions of its codebase attributed to "vibe coding" without traditional security audits.

**Immediate actions:**
- Implement mandatory human-in-the-loop security reviews for all code generated by autonomous agents.
- Use tools that can detect "AI stylistic markers" in code even when metadata tags are removed.
- Treat agent-generated PRs as "untrusted" input during CI/CD pipelines.

## Five Things to Take Into the Rest of the Day

1. **Stop "Public" Agent Builders Immediately.** The Flowise RCE is a case study in why internal orchestration tools should never sit on the public web. If an agent has a "Custom MCP" or "Code Execution" node, it is a remote shell waiting to happen. Move these behind a VPN or Zero Trust tunnel today.
2. **Vibe Coding is the New Shadow IT.** The Georgia Tech data proves that AI-generated code is introducing vulnerabilities at an exponential rate. Your biggest risk isn't a zero-day; it's a "zero-thought" commit from a developer trying to ship a feature with a "vibe coding" tool they don't fully understand.
3. **API Bypasses are the New RCE.** The Fortinet zero-day highlights a shift: attackers are ignoring the frontend and targeting the pre-auth API layers of management software. Your WAF rules for "web traffic" likely don't cover these specialized API endpoints.
4. **Local is the only true isolation.** Projects like Ghost Pepper highlight a growing "Local-Only" AI movement. As cloud providers move toward more aggressive "monitoring" and "data usage" policies, expect the most sensitive security work to migrate completely to local, air-gapped silicon.
5. **The "Guardrail Paradox" is real.** As seen in the Claude Code community discussion, security guardrails that are too restrictive force users to bypass them, creating more risk than the guardrails originally mitigated. Security teams must find a way to make the "safe" path also the "productive" path.
