## Breaking News

### **Codex Joins Anthropic in API Pricing Pivot — All Subscription Usage Sunset Effective Immediately**

Following Anthropic's move yesterday, Codex (OpenAI) announced today, April 5th, that it is switching all users to API-based pricing for agentic workloads. The change removes the ability to use "included" subscription credits for high-volume automated tools like OpenClaw or Cursor. This coordinated tightening of the belt across the two largest agent-platform providers marks the end of the "subsidized agent" era. Usage that previously fell under a flat monthly fee now incurs direct per-token costs, a move both vendors justify as necessary for capacity management during the current automation boom.

Key findings:
- **Codex API Rate Card** | Published April 5, 2026 | Covers all agentic tool-use
- **Transition** | No grace period mentioned for existing workflows; pricing active immediately
- **Impact** | Increases operational costs for "feral" agent deployments by 4x to 10x depending on context window depth

**Immediate actions:**
- Review your model usage in OpenClaw and other harnesses to estimate new monthly burn under pay-as-you-go
- Implement more aggressive token-trimming or summarization steps in agent loops to mitigate cost spikes
- Evaluate open-weight alternatives (Gemma 4, Llama 4) for high-frequency, low-trust tasks that no longer justify premium API costs

## Technical Deep Dives

### **Device Code Phishing Surges 37x — Hijacking OAuth 2.0 Flows for AI Platform Access**

Security researchers at BleepingComputer reported on April 4th that device code phishing attacks have surged 37x this year. The attack abuses the OAuth 2.0 Device Authorization Grant flow — the same flow used to "pair" AI agents like OpenClaw to user accounts. By tricking a user into entering a code on a legitimate-looking but malicious proxy site, attackers can hijack the resulting session token. This gives the attacker the same level of access to AI models and integrated tools as the user, often bypassing MFA since the "secondary" device flow is sometimes less scrutinized than primary logins.

Key findings:
- **Growth** | 3700% increase in observed attack kits since January 2026
- **Vector** | OAuth 2.0 Device Authorization Grant flow (RFC 8628)
- **Tooling** | New automated kits specifically targeting AI developers and agent operators

**Immediate actions:**
- Never enter a device pairing code on a URL you didn't navigate to yourself (e.g., via a link in an email or DM)
- Audit your OpenClaw or AI platform "Authorized Devices" list for any entries you don't recognize
- Educate team members that device-pairing flows are just as sensitive as password entry and can bypass MFA

## Five Things to Take Into the Rest of the Day
1. **The "Flat Fee Agent" is dead.** With both Anthropic and Codex moving to API-only billing for third-party tools, your auto-GPT or OpenClaw budgets just moved from a predictable /mo to a variable (and potentially high) monthly expense. Your first task today is a cost-audit of your active cron jobs and agent loops.
2. **Device code flows are the new password.** Attackers are moving 37x faster on device-code phishing because they know developers are "pairing" tools aggressively without the same scrutiny as a login. If you see a code-entry prompt you didn't trigger, it's an active breach attempt.
3. **BrowserStack operators: Rotate your credentials.** With reports of email leaks today followng the "TeamPCP" infrastructure campaign, assume your testing environments are targeted. If you use BrowserStack to run agents, check your test logs for exfiltration attempts.
4. **Token efficiency is now a security feature.** Now that tokens are billed directly for tools like OpenClaw, "long context" isn't just a performance choice — it's a financial liability. Bloated prompts aren't just inefficient; they're expensive and increase the surface area for indirect injection.
5. **Extension scanning is the new fingerprinting.** LinkedIn's BrowserGate proves that major platforms are actively inventorying your developer toolchain. If your work involves auditing AI agents, do that work in an isolated, extension-free browser profile to avoid leaking your toolkit to third parties.
