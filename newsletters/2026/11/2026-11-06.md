## 1) Claude Code leaked account email in User-Agent headers (community report + staff comments)
**What changed:** GitHub issue #107757 (opened Thu 5:13 PM EST; labels include area:security) says Claude Code put the signed-in user's account email into User-Agent headers on web searches. Top HN story in window (Thu 5:17 PM EST, 1,287 points). An HN user who said they work on Claude Code (Thu 11:24 PM EST) wrote that the account email was added to model context to stop hallucinated @author names, and that when Claude wrote commands it sometimes put that email in the User-Agent as a contact. Fix: remove email from context, due early next week; 2.1.317+ has a built-in privacy mod on by default that still "doesn't prevent all cases"; "the stable channel is still on 2.1.311." A GitHub CONTRIBUTOR (Thu 6:31 PM EST) names the mod `cc-plugin-privacy`. No official Anthropic advisory.
**Limits:** HN staff identity is self-stated; spam causation anecdotal; no user count. Not an official Anthropic bulletin.
**Action:** Move off 2.1.311 where possible; inspect agent egress User-Agents; keep the privacy mod on until the context fix ships.
