### NVIDIA Open-Sources SkillSpector: First Major-Vendor Scanner Purpose-Built for AI Agent Skill Supply-Chain Risk — 64 Detection Patterns, 0–100 Risk Score, Optional LLM Pass at 87% Precision, SARIF Output for CI

**NVIDIA** released **SkillSpector** as an open-source project on **August 3, 2026** (per **Help Net Security's Aug 3 coverage** and the **GitHub repository at `github.com/NVIDIA/SkillSpector`**), a security scanner purpose-built for **AI agent skills** — the Markdown instruction files (sometimes with companion Python scripts) that agents load on trust and that drive modern agent behavior. Per the Help Net Security piece, "a skill is Markdown instructing the agent, sometimes with a Python script beside it that reaches the shell, the environment variables, and the SSH directory. The script is where risk concentrates." The release is the **first major-vendor scanner purpose-built for the AI agent skill supply chain**, and it lands the same morning the **CrowdStrike 2026 Threat Hunting Report** (covered in Headliner 1) documents the 89% surge in AI-enabled malicious activity and the same week the **OpenClaw AI assistant platform announced its VirusTotal + NVIDIA partnership for automated skill analysis** (covered in Community Pulse 2). The structural finding: **a study behind the tool found skills that ship a Python script are 2.12× more likely to be vulnerable**, and **agents load them on trust**.

**The "64 detection patterns, 0–100 risk score, do-not-install past 50" governance primitive.** Per the **Help Net Security** piece, SkillSpector's first pass is static and takes seconds: an **AST walk flags exec, eval, subprocess, and dynamic imports**; a **taint tracker follows environment variables and file contents to network sinks**; **YARA rules match known malware, webshells, and cryptominers**; and **regex analyzers handle the rest of the 64 detection patterns**, covering **prompt injection, credential access, memory poisoning, typosquatted dependencies, and cron-job persistence**. Each finding adds points; executable content multiplies the result by 1.3; **anything past 50 on the scale comes back as do not install**. The governance primitive is the same one the **Island.io 49% of MCP server builds** finding (covered in Breaking News 1), the **HackTricks MCP-ITP 84.2% attack success rate** (covered Jul 31), and the **MCP 2026-07-28 final specification's six authorization SEPs** (covered Jul 31) make from different angles: the **AI agent skill category is now a tier-1 enterprise infrastructure category with documented 64-pattern detection primitives**, and the procurement consequence is the same one the **CrowdStrike 2026 Threat Hunting Report's 88% within-48-hours PoC exploitation** (covered in Headliner 1) and the **Check Point Aug 3 Ruflo CVE-2026-59726** (covered in Breaking News 3) make: every enterprise AI agent RFP now needs an explicit "what is the skill scanning tool" question, an explicit "what is the do-not-install risk threshold" question, and the answers have to be in writing.

**The "optional LLM pass at 87% precision, prompt carries anti-jailbreak instructions" defender-AI primitive.** Per the **Help Net Security** piece, the **second pass is optional, slower, and off until configured**: it needs an **OpenAI-compatible endpoint and a key**, set through `SKILLSPECTOR_PROVIDER`, **defaulting to NVIDIA's own build.nvidia.com**. "Wired up, an LLM reads the flagged code in context, drops false positives, and writes an explanation someone can act on, which the project puts at roughly 87% precision. The prompt carries anti-jailbreak instructions, because the thing under analysis is itself a set of instructions to a model." The defender-AI primitive is the same one the **HackerNoon "You Cannot Filter Your Way Out of Prompt Injection"** piece (covered in Community Pulse 1), the **ISGroup GlobaLeaks 29 confirmed out of 110 candidates** (covered Aug 1-2), and the **OpenAI Codex Security CLI** (covered Aug 1) make from different angles: the **AI-assisted security category is now a tier-1 enterprise procurement category with documented 87% precision and a documented anti-jailbreak prompt**, and the procurement consequence is the same one the **Microsoft MAI-Cyber-1-Flash's 96% on CyberGym** (covered Aug 1) and the **Apple bug-report cap's "experts still have the decisive role"** (covered Aug 2) make: every enterprise AI-assisted security RFP now needs an explicit "what is the LLM-pass false-positive rate" question, an explicit "what is the anti-jailbreak prompt" question, and the answers have to be in writing.

**The "SARIF output for CI, OSV.dev CVE lookup, JSON + Markdown" integration primitive.** Per the **Help Net Security** piece, **dependency checking goes out to the network** — SkillSpector **batches a skill's package list into one query to OSV.dev**, gets back known CVEs, and **caches the answer for an hour**. An air-gapped run falls back to a small built-in list. The terminal output gives a human the score, the file list, and each finding with a line number and a confidence figure; **the same scan writes JSON for scripting, Markdown for a review thread, and SARIF for CI, which puts findings in the same place as the rest of a pipeline's security results**. The integration primitive is the same one the **GitHub Dependabot 3-day cooldown** (covered Jul 27), the **CISA KEV 48-hour deadline** (covered Jul 29), and the **Cato Networks' 45-minute protection** (covered in Breaking News 2) make: the **CI integration primitive is now a tier-1 enterprise vulnerability management category with documented SARIF output**, and the procurement consequence is the same one the **CrowdStrike 2026 Threat Hunting Report's 88% within-48-hours PoC exploitation** (covered in Headliner 1) makes: every enterprise AI agent RFP now needs an explicit "what is the SARIF integration" question, and the answer has to be in writing.

**Why it matters:** First major-vendor scanner purpose-built for AI agent skill supply-chain risk, with 64 detection patterns, 0–100 risk score, do-not-install past 50, optional LLM pass at 87% precision, anti-jailbreak prompt, OSV.dev integration, and SARIF output for CI. The structural signal is the same one the **Island.io 49% of MCP server builds** finding (covered in Breaking News 1), the **CrowdStrike 2026 Threat Hunting Report's 89% AI-enabled surge** (covered in Headliner 1), and the **Check Point Aug 3 Ruflo CVE-2026-59726** (covered in Breaking News 3) make: the **AI agent skill category is now a tier-1 enterprise infrastructure category with a documented first-mover scanner**, and the procurement consequence is that every enterprise AI agent RFP now needs an explicit skill-scanning question, an explicit do-not-install risk threshold question, and the answers have to be in writing. For enterprise security teams: (1) integrate SkillSpector (or equivalent) into the CI pipeline for AI agent skill review, (2) set the do-not-install risk threshold to 50 and document it in the procurement RFP, (3) add the "what is the LLM-pass false-positive rate" question to every AI-assisted security procurement RFP, and (4) treat the AI agent skill category as a tier-1 enterprise vulnerability management category with a documented scanning cadence.
