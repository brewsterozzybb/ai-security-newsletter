### Stealth Security at Black Hat USA 2026: AWS, Google, and Vercel Patch CoreBreak Agent Infrastructure Flaws — Forged Tool Calls Reach Dispatch Without Model Authorization; In Several Paths, the Model Never Ran at All — AWS Bedrock AgentCore CVE-2026-18830 (CVSS 8.6), Google ADK 2.5.0, Vercel AI SDK Harness Packages

**Stealth Security co-founders Hedi Ingber and Aviyam Ivgi** presented on **August 6, 2026** at **Black Hat USA 2026** (per **The Hacker News Aug 6 coverage**) a cross-platform attack pattern they call **CoreBreak** that exploits **insufficient provenance validation between the model decision step and the tool dispatch step** in three major agent infrastructure products: **Amazon Web Services Bedrock AgentCore**, **Google's Agent Development Kit (ADK) for Python**, and the **Vercel AI SDK harness packages** for the Codex and OpenCode coding agents. The attack is structurally different from prompt injection: in several paths, **the model never ran at all**, so system prompts, content filters, and model-level guardrails never intervened. AWS fixed the managed service automatically; **Google fixed the issues in ADK 2.5.0**; **Vercel patched `@ai-sdk/harness-codex` in version 1.0.29 and `@ai-sdk/harness-opencode` in version 1.0.28**. The disclosure is the **first cross-vendor agent infrastructure vulnerability class at Black Hat USA 2026**, and it lands the same day as the **Check Point 11 agent framework vulnerabilities** (Headliner 2).

**The "AWS Bedrock AgentCore CVE-2026-18830 CVSS 8.6" managed-service primitive.** Per The Hacker News Aug 6 coverage, "AWS's security bulletin assigns CVE-2026-18830, with a CVSS v4.0 score of 8.6, to insufficient input validation in the Amazon Bedrock AgentCore harness. An authenticated remote user could place a tool-use content block in the final message of an InvokeHarness request. **The event loop could then dispatch the named tool directly without asking the model.**" The managed-service primitive is the same one the **Check Point Microsoft Agent Framework RCE** (Headliner 2) and the **CoreBreak Vercel AI SDK harness flaws** make from different angles: the **agent infrastructure model-skipping primitive is a tier-1 enterprise vulnerability management category with documented managed-service and open-source precedents**, and the procurement consequence is that every enterprise AI agent infrastructure RFP now needs an explicit "what is the model-skipping-path audit" question, an explicit "what is the InvokeHarness input validation policy" question, and the answers have to be in writing.

**The "Strands SDK still has comparable path" open-source-precedent finding.** Per The Hacker News Aug 6 coverage, "The managed-service fix does not cover a comparable model-skipping path in the open-source Strands Python code, which the researchers say AgentCore's harness is built on. The current upstream event_loop.py calls a helper named _has_tool_use_in_latest_message, and when that check passes, the event loop sets the stop reason to tool_use, takes the latest message directly, and skips model execution." The open-source-precedent finding is the same one the **HashiCorp Terraform MCP Server CVSS 10.0** (Breaking News 2) and the **Check Point Microsoft Agent Framework pre-GA no-CVE** (Headliner 2) make from different angles: the **open-source agent SDK layer is a tier-1 enterprise vulnerability management category with documented model-skipping precedents and documented managed-vs-open-source parity gaps**, and the procurement consequence is the same one the **AWS managed-service fix without Strands fix** makes: every enterprise AI agent SDK RFP now needs an explicit "what is the managed-service-vs-open-source-parity enforcement" question, an explicit "what is the open-source-SDK model-skipping audit" question, and the answers have to be in writing.

### Cloudflare OS Open Sourced: The Observation Log and Gatekeeper Pattern — Every Resource an Agent Reads Gets Recorded, Record Follows Outputs, Credential Never Reaches the Agent

**Cloudflare** announced on **August 6, 2026** (per the **Cloudflare blog** and **Help Net Security Aug 6 coverage**) that it is open sourcing **Cloudflare OS**, the internal agent platform that has been in use by every Cloudflare employee since May 2026. The release ships two repositories on GitHub: **a core, and a starter deployment modeled on how Cloudflare runs the thing internally**. The architecture is the first open-source agent platform with a built-in data-exfiltration prevention primitive that records every resource an agent reads, attaches the record to whatever the agent produces, and uses the record to gate downstream access. The release lands the same day as the **AWS/Google/Vercel CoreBreak agent infrastructure flaws** (Breaking News 1) and the **Check Point 11 agent framework vulnerabilities** (Headliner 2), and it directly addresses the "where did the agent's data go" gap that the **Island.io 33,563 MCP server scan** (Jul 29) and the **CoreBreak model-skipping primitive** (Breaking News 1) make the procurement question.

**The "observation log = downstream access gate" data-exfiltration-prevention primitive.** Per the **Help Net Security Aug 6 coverage**, "Every resource an agent reads gets recorded, the record follows whatever the agent produces, and when a second person opens that output the platform checks them against the underlying data first. An agent builds a live dashboard from a sensitive warehouse table, a coworker opens the dashboard, and the coworker sees nothing unless they could have read the table themselves." The data-exfiltration-prevention primitive is the same one the **Cloudflare Wallets' API-layer spending cap** (Aug 4) and the **Snowflake Cortex AI Gateway's data exfiltration prevention** (Jul 30) make from different angles: the **observation-log-and-downstream-gate primitive is a tier-1 enterprise agent platform category with documented three-vendor precedents**, and the procurement consequence is that every enterprise AI agent platform RFP now needs an explicit "what is the observation-log primitive" question, an explicit "what is the downstream-access-gate primitive" question, and the answers have to be in writing.

**The "Gatekeeper = credential never reaches the agent" credential-isolation primitive.** Per the **Help Net Security Aug 6 coverage**, "Every agent and app inside Cloudflare OS starts with access to nothing.
