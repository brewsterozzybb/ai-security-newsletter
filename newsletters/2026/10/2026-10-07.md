## 1) Anthropic folds Glasswing into a three-tier Cyber Verification Program

**What changed:** [Anthropic](https://www.anthropic.com/news/cyber-verification-program), **Tue 3:00 PM ET**. Reduced cyber blocking on Opus 5.5, Sonnet 5.5, and Mythos 5.1, in three tiers:
- **Defense Access** (SOC/IR, vuln validation): security teams, critical-infrastructure operators "of any size," OSS maintainers, track-record researchers.
- **Red Team Access** (authorized pentesting): organizations only.
- **Specialized Access** (life- and market-critical testing): reviewed "in collaboration with the US government."

Data retention is required for misuse monitoring; once "Enterprise Frontier Safeguards" (EFS) ships "later this fall," eligible orgs can keep that data in cloud infrastructure they control. Until then, orgs with ZDR access to Fable 5.1 or Mythos 5.1 can use CVP with ZDR.

**Vendor claims:** on Anthropic's own benchmark, Defense blocked 46/50 trials; Red Team blocked none and completed 34, which Anthropic equates to its no-safeguards rate. Partners found "at least 129,000 verified" vulnerabilities (Apr–Jul), per survey data from a subset of partners (33 reports). Anthropic calls that an undercount, but it doesn't define "verified" or say whether the count is deduplicated or how many bugs have CVEs. Counter-context ([THN](https://thehackernews.com/2026/10/anthropic-expands-claude-access-for.html), Wed 4:07 AM): VulnCheck's Patrick Garrity found 2 of 300 Anthropic/Glasswing-found bugs exploited in the wild (late-September; background).

**New vs Sep 30:** the tiers and totals. **Evidence type:** lab disclosure. **Questions:** should client SOCs apply for Defense Access? Can red-team vendors accept retention before EFS ships?

## 2) Encrypted prompt injection can make Copilot CLI leak secrets (researcher experiment)

**What changed:** [Adversa AI](https://adversa.ai/blog/cryptographic-context-injection-github-copilot/), **Tue 8:50 AM ET**. In **autopilot mode**, Copilot CLI reads an attacker page holding ciphertext, a key, and a decrypt instruction. It decrypts in its own shell, trusts the output, and ships local files out (`.env.prod` in ~28 seconds). As plaintext, the same text was refused.

`mai-code-1.1-flash` ran the chain in 50% of runs. Two GPT-5.6 models refused. On Adversa's paid test account the vulnerable model wasn't the default; **Auto** routing assigned it in some sessions, and users couldn't see which model they got.

GitHub validated the report (filed Sep 17) but declined to treat it as a vulnerability: the user "explicitly asked Copilot CLI to fetch attacker-controlled content while giving copilot full permissions to act autonomously." Payloads are withheld.

**Evidence type:** vendor-researcher experiment; opt-in mode, unreproduced, no CVE or ITW use. **Why it matters:** filters can't inspect what an agent decrypts, so permissions and egress controls are what count. **Question:** do clients allow autopilot with web fetch, and do they pin models?

## 3) Atlassian CVE-2026-21589: PoC, then exploitation attempts (not KEV)

**What changed:** [watchTowr](https://labs.watchtowr.com/you-wont-hear-about-these-even-in-myths-atlassian-jira-confluence-and-more-pre-auth-arbitrary-file-read-cve-2026-21589/), **Tue 1:01 PM ET**. Atlassian converts `..::` to `../`, enabling one-request unauthenticated webroot reads, including `crowd.properties` (Crowd credentials) on Jira/Crowd.

[Previdian](https://previdian.com/CVE-2026-21589) honeypots logged first attempts Tue afternoon: its timeline says **4:52 PM** and its sensor table says **5:55 PM**. At an 8:34 AM Wed fetch it counted 22 attempts from 4 IPs in 3 countries. [THN](https://thehackernews.com/2026/10/atlassian-data-center-flaw-draws.html) quotes Previdian's CEO saying "within two hours" of public exploit details, but both Previdian stamps fall about four to five hours after watchTowr's 1:01 PM post.

**New vs Oct 6 Feed:** working paths are public and attempts are observed. A Nuclei template appeared overnight (12:31 AM Wed, per Previdian). **Evidence type:** PoC plus honeypot attempts, not confirmed compromises; **not in CISA KEV**. **Action:** upgrade, or apply Atlassian's interim mitigations as reported by THN (off-internet, WAF rule, Tomcat RewriteValve, Bitbucket `urlrewrite.xml`). Consider rotating Crowd credentials on hosts that were exposed while unpatched.

## 5) MCP TypeScript SDK CVE-2026-104850: OAuth secrets sent to a server-chosen auth server (formalization)

**What changed:** [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-104850), **Tue 1:17 PM ET**. This formalizes the [Sep 30 GHSA](https://github.com/modelcontextprotocol/typescript-sdk/security/advisories/GHSA-6qxp-vccf-f47h); fixes shipped Sep 28. A malicious MCP server could name its own authorization server and receive stored `refresh_token` and `client_secret` (1.x) "with no user interaction."

**Affected:** `@modelcontextprotocol/sdk` 1.12.0–1.30.1 and some `client` 2.x configs; only HTTP OAuth clients that may reach untrusted servers. CVSS 3.1 7.5 (GitHub CNA).

**Evidence type:** official advisory; no exploitation, not KEV. **Why it matters:** it's the reference SDK. **Action:** upgrade (`sdk` 1.31.0 / `client` 2.2.0), but upgrading alone isn't enough: pass `expectedIssuer` to bundled providers, and add `issuer` to, or clear, credentials saved before the upgrade. Rotate secrets and revoke tokens for any client that may have reached an untrusted server. Until you can upgrade, connect OAuth clients only to trusted servers.

## Take into the day / Worth keeping

1. **Encryption sidelines content filters, and "Auto" routing is a security setting.** A code-executing agent can decrypt instructions no classifier saw; the router picks whose refusals you get. **Use:** workshop question: "Can one autonomous session fetch, execute, and egress, and which models can your router pick?" **Source:** Adversa, Oct 6. **Limits:** one unreproduced vendor experiment in opt-in mode; GitHub disputes it's a vuln; generalization ours. **Tags:** `encrypted-prompt-injection`, `model-routing`.
2. **Bind agent OAuth credentials to their issuer.** **Use:** assessment check: does each MCP client pin its authorization server? **Source:** MCP SDK GHSA, Sep 30 / NVD, Oct 6. **Limits:** one SDK; that other clients share it is our untested inference. **Tags:** `mcp-oauth`.
3. **`..::` in Atlassian resource paths.** **Use:** detection idea (untested): flag `/download/resources/` requests containing `..::` or `WEB-INF`. **Source:** watchTowr, Oct 6. **Limits:** built from published PoC paths; variants may evade. **Tags:** `cve-2026-21589`.
4. **AI-found bugs don't stay private.** OpenSSH reports independent rediscovery of AI-found bugs and infers adversaries can find them too. **Use:** presentation point, beside Glasswing (labeled vendor survey). **Source:** OpenSSH 10.6 notes, Oct 6. **Limits:** one project; no counts. **Tags:** `ai-vuln-discovery`.
