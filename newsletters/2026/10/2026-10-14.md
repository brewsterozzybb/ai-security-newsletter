## 1) Visual Studio Copilot / SSMS: trailing-dot bypass of the MCP/settings guard (CVE-style main 1 of 3; AI-native)

**What changed:** Johann Rehberger's [Embrace The Red writeup](https://embracethered.com/blog/posts/2026/visual-studio-copilot-remote-code-execution/) (**Tue 6:00 PM**) and Microsoft's fix for [CVE-2026-103572](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-103572) (Patch Tuesday **10:00 AM**, CVSS 8.8) cover a bug in shared `Microsoft.VisualStudio.Copilot.Core.dll`. The agent should refuse writes to `.mcp.json` and settings files. A trailing period (`.mcp.json.`) fails the string check; Win32 strips it on write, so the agent can enable a malicious MCP server or rewrite `ripgrepPath`. Indirect prompt injection can drive it. MSRC FAQ: malicious prompt over the network, UI:R with Copilot.

Same drop: **CVE-2026-102232** (AI coding agent modifies a lifecycle-hook file without expected confirmation; AC:H) and **CVE-2026-102851** (sandboxed MCP server writes into another sandbox's directory).

**Evidence type:** official advisory + researcher experiment; not KEV. **Why it matters (our read):** the guard compared strings, not canonical paths; MCP config was the privilege boundary. **Action:** patch VS/SSMS/VS Code; ask whether MCP enablement and lifecycle hooks still need a human gate if the agent is compromised.

## 2) Gemini 4 Argon goes global; model card "cannot rule out" cyber CCL (material follow-on to Oct 1 Fairwind) (AI-native; lab disclosure)

**What changed (material vs Oct 1 Fairwind-only rollout):** Google/DeepMind's [Gemini 4 Argon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/) is now "available for everyone" (RSS **Tue 12:00 PM**), with a [safety and security post](https://blog.google/innovation-and-ai/technology/safety-security/gemini-4-model-safety-security/) (**2:00 PM**) and [model card](https://deepmind.google/models/model-cards/gemini-4-argon/) (Published: October 2026, date-only; linked from the safety post). The **model card** says Google **cannot rule out** the Frontier Safety Framework cybersecurity Critical Capability Level ("Uplift Level 1") or the biological CBRN CCL (plus a Stealth/Situational Awareness TCL), and that safety cases bring residual risk below those thresholds after mitigations. The **safety post** (not the model card) gives Google's numbers: all 12 end-to-end simulated cyberattack scenarios (prior gen five); Gray Swan IPI 0.7% over 15 adaptive attempts; Fairwind expanding to more trusted defenders. [Irregular](https://www.irregular.com/research/assessing-gemini-4-argon-against-offensive-security-benchmarks) (date-only Oct 13) reported the same 12/12 on a private subset under elicitation without out-of-model safeguards. [Fairwind cyber page](https://deepmind.google/models/gemini/cyber/) describes the defender build.

**Evidence type:** lab/product disclosure (global GA + model-card residual-risk case); Irregular corroborates the 12/12 elicitation count only. **Limits:** CCL/IPI/safety-case figures are Google's; model card is date-only "October 2026." **Our read:** the material update vs Oct 1 is public GA plus an explicit "cannot rule out" cyber CCL case—use that when clients ask what residual-risk language means at frontier cyber capability, and who gets Fairwind.

## 3) Ivanti Connect Secure: unauthenticated root chain in the wild; two of three bugs patched; KEV due Oct 16 (CVE-style main 2 of 3; general cyber)

**Why a main:** CISA KEV, confirmed limited exploitation on internet-facing VPN appliances, three-day federal due date, unfinished privilege-escalation fix.

**What changed:** [Volexity](https://www.volexity.com/blog/2026/10/13/a-series-of-unauthenticated-events-chained-exploitation-of-ivanti-connect-secure-zero-days/) (**11:32 AM**) documented UTA0576 on fully patched **22.8R2.4** from Oct 3: `welcome.cgi` auth bypass via `X-DSCGI-PATH`, `wu.cgi` race → `cgi-server`, then `dsinvoked`/DSCache → root. Ivanti tracks the first two as [CVE-2026-104935](https://www.cve.org/CVERecord?id=CVE-2026-104935) (CVSS 8.6; **11:31 AM**); Integrity Checker Tool misses the in-memory chain. Fixed: **22.8R2.5**, **25.1.1.2**, **25.1.3.0/25.1.3.1** (22.7R2.14 and prior unaffected). Root step still unpatched ("coming weeks"). Post-exfil: AD/LAPS/BitLocker searches, log wiping. CISA KEV same day (**due Oct 16**). [BleepingComputer](https://www.bleepingcomputer.com/news/security/ivanti-warns-of-connect-secure-zero-day-exploited-in-attacks/): Shadowserver **>5,500** exposed ICS.

**Action:** upgrade now; treat internet-exposed units as compromise-suspect; do not rely on ICT alone.

**Evidence type:** researcher experiment / vendor award claim (Google award page not fetched). **Limits:** chain is patched. **Our read:** a dated, costed example that AI-assisted offense can compress a Chrome full-chain from months to days.
