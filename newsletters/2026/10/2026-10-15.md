## 1) Claude Code Desktop "SneakPeek": preview pane could leak local secrets (disclosed Oct 14; fixed Aug 17) (CVE-style main 1 of 3; AI-native)

**What changed:** Noma's [write-up](https://noma.security/noma-labs/sneakpeek-how-the-preview-pane-in-claude-code-desktop-can-exfiltrate-your-data) (Oct 14, date-only; [press release](https://www.prnewswire.com/news-releases/noma-labs-uncovers-critical-security-vulnerabilities-in-claude-code-desktop-app-cvss-8-7-302908539.html) **Wed 9:00 AM**) explains the bug. HTML under 256KB rendered with a no-script CSP. Larger files loaded from disk as `file://` with no CSP and no request filtering. A padded "coverage report" in a cloned repo could therefore exfiltrate SSH keys, cloud/GitHub tokens and Claude OAuth tokens. Per Noma, a bypass of Anthropic's Jul 24 patch was reported the same day, via a `blob:` Web Worker. The full fix shipped Aug 17 (Claude Desktop 1.30096.1+, auto-update). Noma says Anthropic scored it CVSS 8.7 (v4.0) and a GitHub advisory and CVE are "pending publish" (none listed as of 8:44 AM Thu).

**Evidence type:** researcher disclosure (coordinated); no exploitation claimed. **Prerequisite:** the victim clones the repo and asks Claude to review the file (no separate approval). **Our read:** the renderer showing untrusted content was the hole, not the model. **Action:** confirm Desktop ≥1.30096.1 on developer endpoints; keep long-lived credentials off agent hosts.

## 2) Cisco Secure Email Gateway CVE-2026-76519: email attachment → root; exploited; KEV (CVE-style main 2 of 3; general cyber, KEV + unauthenticated)

**What changed:** Cisco's [advisory](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-esa-afw-zqYJkjxp) (**Wed 12:00 PM**, CVSS 9.8) describes a path traversal in AMP file-reputation handling. A crafted attachment lets an attacker write files and run commands as root. It applies when File Reputation is enabled and Content Scanner Tools is older than 25.3.0.5525. Fixes are AsyncOS 15.5.5-014 / 16.5.0-780 or a Content Scanner Tools update (no restart). There is no workaround. Cisco says PSIRT learned of active exploitation in October and warns that root attackers "may remove or hide evidence." CISA added it to KEV the same day, due Oct 17.

**Action:** verify the Content Scanner Tools version, run Cisco's `System Security` log check, and review off-box network logs.

## 3) Anthropic: red teams found Claude could miss split-up election-abuse campaigns (AI-native; lab disclosure)

**What changed:** Anthropic's [midterms post](https://www.anthropic.com/news/2026-us-midterms) (**Wed 2:33 PM**) reports that ISD and the McCain Institute tested Claude in the US, Israel and Brazil. Claude "reliably refused a single harmful request" but "could miss a malicious campaign" broken into innocuous steps. Anthropic says it added classifiers for "novel and multi-step misuse." It says it banned accounts used by foreign-based operators of a fake news site and by fabricated-news ad-revenue schemes.

**Evidence type:** lab disclosure. No miss rates or classifier results were published, and we did not fetch the ISD/McCain reports. **Our read:** per-request filtering alone misses campaign-style misuse.

## 4) PAN-OS CVE-2026-0322: management-interface root RCE; "very limited exploitation"; KEV (CVE-style main 3 of 3; general cyber)

**What changed:** Palo Alto's [advisory](https://security.paloaltonetworks.com/CVE-2026-0322) (**Wed 12:00 PM**) covers a code injection. An **authenticated** attacker with network access to the management interface can get root on PA-Series/VM-Series firewalls and Panorama (CVSS 4.0 PR:H, i.e. high privileges); Cloud NGFW and Prisma Access are unaffected. There is no workaround. CISA added it to KEV the same day, due Oct 17.

**Evidence type:** official advisory + vendor-observed exploitation + KEV. **Limits:** needs high-privilege (PR:H) credentials and a reachable management interface. **Action:** patch, take management off untrusted networks, and review admin logins.
