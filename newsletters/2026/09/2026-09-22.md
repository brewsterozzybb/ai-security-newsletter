## 1) Meta Muse — macOS AI-agent 0-day → dictation-endpoint / token hijack (Wardle / Ars)

Patrick Wardle discloses that Meta’s **Muse** assistant (broad OS + WhatsApp/email/calendar/social permissions; cloud transcription) exposes undocumented settings so **any locally installed app or terminal command** can change the transcription endpoint. An attacker points it at their server, receives Muse’s auth token, and drives the agent’s already-granted privileges — including via a **ClickFix**-style lure. Ars Technica (Dan Goodin) **Sep 21, 2026 ~6:24 pm ET** (~**22:24Z**); thin HN **2026-09-21T23:08Z** (~8 pts). Same day Amazon blocked Muse shopping on amazon.com — **ToS/commerce, not the vuln fix**.

**Evidence type:** researcher experiment / disclosure (Wardle) + press (Ars). **Not** a CVE. Do **not** claim Meta patched (no published advisory; PoC deferred to Objective by the Sea, November). Needs local code execution or ClickFix — not internet RCE against Meta. Do not invent exploit steps beyond Ars.

**Consulting angle:** inventory Muse (and peer agents) on managed Macs; treat local untrusted code as full agent compromise; demand settings/endpoint authz and on-device transcription where possible; ClickFix training.

Sources: Ars — https://arstechnica.com/security/2026/09/muse-metas-extraordinarily-privileged-ai-assistant-has-a-serious-0-day/ ; Forbes (Amazon block) — https://www.forbes.com/sites/jonmarkman/2026/09/21/amazon-blocks-metas-new-muse-ai-agent-from-shopping-on-amazoncom/

## 3) MCP-for-Stata — `ado_package_install` → Stata `shell` RCE (CVE-2026-55071)

NVD published **CVE-2026-55071** on **2026-09-21T15:17:29.450Z** (CVSS 3.1 **8.4**) against **SepineTam/mcp-for-stata**: `ado_package_install` concatenates user-controlled `package` into `ssc install {package}` with **no sanitization**; newlines inject Stata commands including **`shell` / `!`** → **OS RCE** as the MCP server user. Tool is on the default **`all` profile**. Fixed **1.19.0**. GHSA/fix are **June 2026 background** — **lead on NVD formalization**.

**Evidence type:** official advisory (NVD + GHSA) + vendor patch. Needs MCP tool / Python API invoke (AV:L). Continues Prism’s MCP tool-arg trust-boundary theme.

**Consulting angle:** inventory Stata-MCP; upgrade **≥1.19.0**; disable ado-install tools in production agent profiles; never expose MCP HTTP without authn.

## 4) “Equation of Compromise” — mathmain/mathsbase npm encrypted-loader RAT (JFrog)

**JFrog Security Research (21 Sep 2026)** teardowns typosquat **mathjs** clones (`mathsbase`, `mathmain`, `math-universe`, plus a 6-month cluster): **AES-256-GCM encrypted loader** after `lusolve()`; payload decrypts only when LU factor of a specific **3×3 Pascal matrix** is the scrypt password. Implant uses **Sepolia/Base-Sepolia + Slack/Telegram**, a LICENSE infection marker, and **GitHub Actions download farms**. SafeDep reproduces the same day; HN **2026-09-21T18:33Z** (~**133** pts). Material new: **trigger recovery + campaign linkage Sep 21** (SafeDep page started Sep 18).

**Evidence type:** observed incident + researcher experiment (JFrog / SafeDep). Loader inert until trigger/`lusolve` path. Second-stage cargo still encrypted. Download counts manipulated — do not treat popularity as trust.

**Consulting angle:** block listed packages; hunt `lib/cjs/utils/event.js` + `graph.js`, `subwatcher` mode 755, LICENSE marker; treat “millions downloads / zero dependents” as a signal — especially for agents that `npm install` unpinned deps.

Sources: JFrog — https://research.jfrog.com/post/equation-of-compromise/ ; SafeDep — https://safedep.io/mathmain-encrypted-loader/ ; HN — https://news.ycombinator.com/item?id=49791378

## 5) Fluent Bit Secure-Forward — remote stack buffer overflow (CVE-2026-61674)

NVD published **CVE-2026-61674** on **2026-09-21T17:17:36.663Z** (CVSS 4.0 **9.2** Critical): `secure_forward_pong` `memcpy`s attacker-controlled PONG[2] into a **32-byte** stack `msg` with no length/type check. Malicious or MITM Secure-Forward destination → DoS or RCE; under opt-in **`--supervisor`**, fork-without-exec freezes canary/ASLR for leakless BROP (demonstrated root in advisory). Fixed **v5.0.8**. GHSA **Sep 8** / release **Jun 24** are **background** — **lead on NVD formalization**.

**Evidence type:** official advisory (NVD + GHSA) + researcher PoC in advisory. Needs `out_forward` Shared_Key path + attacker control/MITM (TLS verify often off). **Full leakless RCE path needs `--supervisor` (opt-in).**

**Consulting angle:** logging agents fan out fleet-wide — patch Fluent Bit; enable TLS verify; reconsider `--supervisor`.

Sources: NVD — https://nvd.nist.gov/vuln/detail/CVE-2026-61674 ; GHSA-jrp8-r9hx-gf73 — https://github.com/fluent/fluent-bit/security/advisories/GHSA-jrp8-r9hx-gf73 ; fix — https://github.com/fluent/fluent-bit/releases/tag/v5.0.8
