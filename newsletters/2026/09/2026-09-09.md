## 1) DeepSeek Harness sandbox escape — CVE-2026-82533

NVD first published **CVE-2026-82533** on **2026-09-08T17:18:36Z** (inside this window). DeepSeek Harness (`dsh`) before `0.1.2-alpha.1` exposes an unauthenticated local HTTP control-plane API that trusts the client-supplied `Host` header rather than the TCP peer. OX Research (researcher write-up dated Sep 8; disclosure to VulnCheck Aug 24; fix Aug 27) reports that the OS sandbox left loopback networking open, so a sandboxed agent could call that API, elevate to `danger-full-access` with approvals disabled, and run unconfined. If the port is reachable beyond localhost, the same interface allows unauthenticated remote control and conversation export without a key. VulnCheck CNA rates CVSS **9.4** (v4).

This is a researcher experiment plus official CVE, not observed mass exploitation in KEV. Preconditions include agent command execution (e.g. from untrusted task text). Star-count marketing on the OX page is vendor narrative and is not treated as prevalence evidence.

**Consulting angle:** treat local agent harnesses as identity brokers. Ask whether sandbox profiles unshare the network namespace, and whether control-plane auth binds to the connection peer rather than a forgeable header.

Sources: NVD CVE-2026-82533, published 2026-09-08T17:18:36Z — https://nvd.nist.gov/vuln/detail/CVE-2026-82533 ; VulnCheck advisory, 9/8/2026 — https://www.vulncheck.com/advisories/deepseek-harness-alpha-1-authentication-bypass-via-host-header-spoofing ; OX Research, Sep 8, 2026 — https://www.ox.security/blog/cve-2026-82533-deepseek-harness-ai-agent-sandbox-escape/

## 2) Copilot + VS Code info disclosure — CVE-2026-81380 / CVE-2026-81381

Microsoft released two Important information-disclosure issues for **GitHub Copilot and Visual Studio Code** on **Sep 8, 2026** (NVD published both ~**2026-09-08T18:20:54Z**). Affected VS Code line is **1.0.0 through before 1.136.2**; remediate at **≥ 1.136.2**.

- **CVE-2026-81380** (CWE-77 command injection): NVD/MSRC summary — improper neutralization of special elements in a command allows an unauthorized attacker to disclose information over a network. CVSS 5.3 (`AV:N/AC:H/PR:N/UI:R`). CISA SSVC at publication: exploitation none.
- **CVE-2026-81381** (CWE-522): MSRC FAQ — can expose a **work-account sign-in access token**; that token could allow access to data/services the user is authorized to use. CVSS 6.5 (`AV:N/AC:L/PR:N/UI:R`). SSVC: exploitation none at publication.

Both require user interaction per the CVSS vectors. Full MSRC executive detail for 81380 is JS-gated in this dig; wording above sticks to NVD + MSRC FAQ/search summaries. Do not upgrade secondary “agent mode” packaging into a confirmed mechanism without reading the live MSRC page.

**Consulting angle:** patch Copilot/VS Code fleets on the 1.136.2 line; treat work-account token exposure as an identity incident class, not only an IDE bug.

## 4) MemSentry — agent memory-poisoning detection (arXiv first announce)

arXiv announced **MemSentry** (`2609.08747`) at **2026-09-08T13:40:13Z**. The preprint frames **memory poisoning** in agentic systems with persistent memory: adversarial content stored in long-term memory that later suppresses alerts, escalates privilege, alters trust, or overrides policies without changing weights or system prompts. Authors propose a formal, configuration-driven detection approach.

**Evidence type:** researcher experiment / preprint. Evaluation claims are not independently audited here. Useful as a control-class pointer for persistent-memory agents, not as a production detection you can drop in tomorrow.

Source: https://arxiv.org/abs/2609.08747v1 — announced 2026-09-08T13:40:13Z.
