## 1) CISA KEV 2026.09.14 — Cisco ESA SQLi → root (CVE-2026-76461)

CISA released KEV catalog **`2026.09.14`** (`dateReleased` **2026-09-14T19:00:02.426Z**) and added **CVE-2026-76461**. Cisco’s PSIRT (first published **2026-09-14T16:00:00Z**) says SQL injection in AsyncOS email parsing on **Secure Email Gateway** can let an unauthenticated remote attacker run commands as **root**. Cisco states it became aware of **active exploitation in September 2026**; no workarounds; BOD due **2026-09-17**; forensic triage **Yes**. Fixed builds include **15.5.5-014**, **16.0.4-302**, **16.5.0-780** (preferred).

**Evidence type:** official advisory + vendor-confirmed observed exploitation. **Not** AI-specific — included for ops significance (email edge → root, three-day federal clock). Sep 14 edition still had catalog **2026.09.11**; this is the first KEV bump since then.

**Consulting angle:** patch/isolate SEG now; assume local logs may be incomplete if root was obtained — correlate with external firewall/network telemetry. Cisco’s IoC language around `COPY … TO PROGRAM` in mail logs is a reminder that SQL→OS escapes remain a live class wherever tools or agents can drive databases.

Sources: CISA alert, Sep 14, 2026 — https://www.cisa.gov/news-events/alerts/2026/09/14/cisa-adds-one-known-exploited-vulnerability-catalog ; KEV JSON `catalogVersion` 2026.09.14 — https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json ; Cisco PSIRT, 2026-09-14T16:00Z — https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-esa-inj-2bLVGmhX ; NVD — https://nvd.nist.gov/vuln/detail/CVE-2026-76461

## 2) Langflow — scanner “validated: true” while running socket/urllib (CVE-2026-12944)

NVD published **CVE-2026-12944** on **2026-09-14T22:16:56.950Z** (CVSS **9.6**): Langflow OSS **1.0.0–1.10.0** incomplete `DANGEROUS_IMPORTS` blocklist omits `socket`/`urllib`, so authenticated component submission can execute network/code paths during “validation,” returning `validated: true` while enabling IMDSv1 SSRF / credential theft and related impact. Remediation: **≥1.10.1**. Same evening NVD also listed MCP/SSRF siblings (**CVE-2026-12763**, **12765–12767**, plus **CVE-2026-17628** password-change).

**Evidence type:** official advisory (IBM PSIRT + NVD). **Underlying IBM bulletin for 12944 is July 2026** — in-window novelty is **formal NVD publication**, not a brand-new technical find. MCP sibling IBM node initial publish **Sep 8** is background; NVD clocks are what land in this freeze.

**Consulting angle:** treat component/upload “scanners” as untrusted execution paths; ask whether validation runs the payload. Pin Langflow past the listed floors and inventory MCP/API auth on the same host.

Sources: NVD CVE-2026-12944, 2026-09-14T22:16:56.950Z — https://nvd.nist.gov/vuln/detail/CVE-2026-12944 ; IBM PSIRT (background, Jul 2, 2026) — https://www.ibm.com/support/pages/node/7278919 ; NVD CVE-2026-12763 — https://nvd.nist.gov/vuln/detail/CVE-2026-12763

## 3) PraisonAI — unauth MCP connect RCE + open HTTP MCP (CVE-2026-57124 / 57139)

NVD published **CVE-2026-57124** on **2026-09-14T16:17:13.417Z** (CVSS **9.8**): default UI hosts expose `POST /api/mcp/connect` without mandatory auth; caller-controlled `command`/`args` start a local process via `StdioMCPClient`; UI binds **`0.0.0.0`** by default — fixed **4.6.59**. On **2026-09-15T11:17Z**, NVD also published **CVE-2026-57139** (HTTP MCP `startHttp()` with no host restriction and no auth — fixed **1.7.2** / related **v4.6.60** notes) and **CVE-2026-57134** (auth-policy bypass accepting invalid credentials).

**Evidence type:** official advisory (GHSA + NVD). **GHSAs ~June 2026** — novelty is NVD formalization. Reachability to default-bound ports is a prerequisite. Confirm Python UI vs TypeScript MCP package pins separately.

**Consulting angle:** inventory multi-agent frameworks that ship MCP connect endpoints or HTTP MCP servers as default attack surface — same class as LiteLLM/Bifrost-style “stdio connect = RCE” and “HTTP MCP without auth.”

   - **Use:** workshop question / assessment check for upload or component scanners.  
   - **Source:** NVD CVE-2026-12944, 2026-09-14 (above).  
   - **Limits:** July IBM bulletin background; requires authenticated component submission per CVSS.  
   - **Tags:** `false-validation` `llm-platform-ssrf`
