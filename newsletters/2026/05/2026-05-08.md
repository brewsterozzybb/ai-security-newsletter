# AI Security Newsletter — May 8th, 2026

*A daily brief on vulnerabilities, governance, and the hardening of the agentic stack.*

### 1. Headliners

**"TrustFall" Discovery: One-Click RCE in Claude Code and Major Coding CLIs**
A critical disclosure by Adversa AI, dubbed "TrustFall," has revealed a systemic vulnerability in the trust model of popular AI coding agents, including Claude Code, Gemini CLI, Cursor CLI, and GitHub’s Copilot CLI. The flaw exploits project-scoped configuration files—specifically `.mcp.json` and `.claude/settings.json`—which can be manipulated in a cloned repository to enable malicious Model Context Protocol (MCP) servers without explicit per-server consent. The moment a developer clicks "Yes, I trust this folder" on the tool's standard initialization prompt, the malicious server is spawned as an unsandboxed local process with the developer’s full system privileges. This marks the third major CVE-class issue related to project-scoped settings in Claude Code in the last six months, raising questions about whether "folder trust" is a sufficiently granular security boundary for agentic tools.

**Microsoft Identifies "Prompts as Shells" Vulnerability in Semantic Kernel**
Microsoft’s Defender Security Research Team disclosed dual vulnerabilities in the Semantic Kernel framework that allow for Remote Code Execution (RCE) through orchestrated prompt injection. By targeting agents utilizing the Search Plugin with In-Memory Vector Store, attackers can craft injections that cause the framework to trust malicious data parsed from search results. This allows the attacker to drive the agent to execute actions beyond its intended scope, effectively turning the agent’s own tool-calling capabilities into a remote shell. Microsoft has issued a fix, but the research highlights a persistent architectural weakness: the inability of current frameworks to distinguish between legitimate system instructions and attacker-controlled data returned by internal tools.

### 2. Breaking News

*   **AWS MCP Server Reaches General Availability**: Amazon Web Services has announced the GA of its managed Model Context Protocol (MCP) server. The move brings MCP—originally an Anthropic specification—into the core AWS infrastructure, providing IAM-based guardrails, CloudWatch observability, and sandboxed Python execution for agents interacting with AWS APIs. This signal suggests that MCP is winning the battle for agent-to-tool standardization in the enterprise.
*   **Active "Indirect" Attacks Observed in the Wild**: A joint report from Google and Forcepoint confirms that indirect prompt injection (IPI) has graduated from academic PoC to active weaponization. Researchers documented real-world campaigns targeting Grafana and Docker platforms, where malicious instructions hidden in web pages or logs trick AI agents into exfiltrating financial data and infrastructure telemetry through legitimate "image-render" requests. IPI attempts increased by 32% between November 2025 and February 2026, and the sophistication is expected to rise as attackers move from simple exfiltration to destructive payloads.
*   **Microsoft Releases Agent Governance Toolkit (AGT)**: To address the "shadow MCP" risk, Microsoft has open-sourced AGT, a governance layer for .NET specifically designed to solve the authorization gap in the Model Context Protocol. AGT allows teams to wrap MCP tool calls in YAML-based policies, enabling deterministic gating of destructive actions (like `DROP TABLE`) and automatic sanitization of both inputs and tool responses before they re-enter the model’s context. The toolkit includes `McpSecurityScanner` for definition auditing, `McpGateway` for per-call enforcement, and `McpResponseSanitizer` to strip credentials from tool outputs.
*   **Lovable "Insecurity" Breach Affects 5,000+ AI-Built Apps**: A Wired report by Andy Greenberg details how researchers found that over 5,000 web applications built using "one-click" AI generation tools (Lovable, Base44, Replit) were deployed without even basic authentication. Approximately 40% of these exposed sensitive user data or internal environment variables. This "security debt" is being created as AI tools lower the barrier to deployment while ignoring standard DevSecOps practices like identity management and secret scanning.

### 3. Technical Deep Dives

**The Metadata Vector: "Comment and Control"**
The "Comment and Control" vulnerability class, disclosed by researchers at Johns Hopkins and Wyze Labs, demonstrates that production AI agents often treat platform metadata (like PR titles, issue bodies, and HTML comments) as "safe" system-level data. By embedding payloads in these unquoted fields, attackers triggered credential exfiltration in three major environments simultaneously:
*   **Claude Code**: Captured `ANTHROPIC_API_KEY` and `GITHUB_TOKEN` via PR title injection.
*   **Gemini CLI**: Exfiltrated `GEMINI_API_KEY` through fake "Trusted Content Section" blocks.
*   **GitHub Copilot Agent**: Scraped tokens via HTML comments (invisible to reviewers) that were exfiltrated in base64-encoded committed files.
The lack of public CVEs for these critical fixes remains a point of contention in the security community, as it complicates patch tracking for enterprise compliance teams.

**TrustFall: The Mechanics of Settings Injection**
The TrustFall exploit depends on the "Managed Scope" hierarchy in agent settings. While Anthropic has blocked *some* global overrides at the project level, it left `enabledMcpjsonServers` and `permissions.allow` accessible to project-scoped JSON files. When a user trusts a folder, the CLI merges the local `.mcp.json` into its active runtime. Because many developers treat "git clone" as a safe operation, the TrustFall PoC successfully demonstrates exfiltrating SSH keys and environment variables (via `env` tool) before a single line of code is ever reviewed or a manual tool call is made.

### 6. Five Things to Take Into the Rest of the Day

1.  **Trust is Not Transitive**: Just because you trust a repository’s source code doesn’t mean you should trust the hidden configuration files (`.mcp.json`, etc.) that configure your AI agent.
2.  **Managed Scopes are Mandatory**: Enterprises must enforce "Managed Scopes" for AI client settings via IT policy to prevent malicious repos from enabling unvetted tool servers.
3.  **The Metadata Surface is Hot**: If an agent reads it (PR titles, issue comments, commit messages), it must be treated as untrusted input. Sanitize your metadata.
4.  **RAG is a Supply Chain Risk**: If your RAG pipeline ingests external web content without filtering for adversarial instructions, you are running an unauthenticated shell.
5.  **CVE Silence is the New Normal**: Major AI vendors are patching critical prompt-injection vulnerabilities without public CVEs. Relying on NVD alone for AI security posture is no longer sufficient.
