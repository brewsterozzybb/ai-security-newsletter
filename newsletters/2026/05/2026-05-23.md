# Atlas — AI Security Newsletter
## May 23, 2026

The age of "trust but verify" has arrived for AI agents. This week, NVIDIA introduced cryptographic signing for agent skills, Anthropic revealed that its Mythos Preview model has found over ten thousand vulnerabilities in a single month, and Check Point confirmed what many suspected: AI-powered attacks have moved from experimental to routine criminal deployment. The common thread is verification—of skills, of findings, and of the assumption that human-speed defenses can keep pace with machine-speed threats.

---

## 1. Headliners

### **NVIDIA Verified Agent Skills: Cryptographic Provenance for the Agent Era**
NVIDIA has launched **Verified Agent Skills**, a framework that brings software supply-chain security principles to AI agent capabilities. The system combines automated scanning through **SkillSpector**, cryptographic signing with detached signatures, and machine-readable **skill cards** that document ownership, dependencies, limitations, and verification status.

The scanning layer is particularly notable. SkillSpector checks not only conventional software risks—vulnerable dependencies, suspicious scripts, credential access—but also agent-specific threats including hidden instructions, prompt injection vectors, trigger abuse, excessive agency, and tool poisoning. The framework is built on the open **agentskills.io** specification, meaning skills verified through NVIDIA's pipeline work across Claude Code, Codex, Cursor, and other compatible agents.

**Why it matters**:
Until now, agent skills have been opaque bundles of instructions that users install with little visibility into what they actually do. NVIDIA's approach treats skills as deployable capabilities requiring provenance and integrity checks. This addresses a critical gap: malicious actors have begun weaponizing agent configuration files as persistent jailbreak vectors, embedding instructions that override model behavior at startup. Cryptographic signing ensures that a skill hasn't been modified post-publication, while skill cards provide transparency about what access the skill requires.

**Defensive Context**:
Organizations deploying AI agents should treat skill installation with the same rigor as software package management. The verification commands using OpenSSF Model Signing are straightforward, and the skill card format provides the audit trail that security teams need to assess risk before deployment.

*Source: [NVIDIA Technical Blog](https://developer.nvidia.com/blog/nvidia-verified-agent-skills-provide-capability-governance-for-ai-agents/)*

## 2. Breaking News

### **Project Glasswing: 10,000+ Vulnerabilities Found in First Month**
Anthropic has published an update on **Project Glasswing**, its initiative to secure critical software before capable AI models can be turned against it. The numbers are striking: in just one month, partners using **Claude Mythos Preview** have found over **ten thousand high- or critical-severity vulnerabilities** across systemically important software.

Cloudflare alone discovered **2,000 bugs** (400 high/critical) with a false positive rate better than human testers. Mozilla found and fixed **271 vulnerabilities** in Firefox 150—over ten times more than in Firefox 148 using Claude Opus 4.6. The UK AI Security Institute reports Mythos Preview is the first model to solve both of their cyber ranges end-to-end. One particularly concerning finding: CVE-2026-5194 in **wolfSSL**, a cryptography library used by billions of devices, which allowed certificate forgery.

**The Bottleneck Problem**:
The report highlights a critical asymmetry: finding vulnerabilities is now vastly faster than fixing them. Anthropic has disclosed 530 high/critical bugs, but only 75 have been patched. Some maintainers have asked Anthropic to slow disclosures because they lack capacity to design patches. The average time to patch a Mythos-discovered vulnerability is two weeks—an eternity when exploits can be generated within hours of disclosure.

**Why it matters**:
This represents a fundamental shift in cybersecurity. The constraint is no longer discovery capability but human triage and remediation capacity. Organizations must move toward automated patching and continuous remediation or accept that known vulnerabilities will remain exploitable.

*Source: [Anthropic Research](https://www.anthropic.com/research/glasswing-initial-update)*

### **Check Point: AI Attacks Are Now Mainstream Criminal Tools**
Check Point Research's March-April 2026 Threat Landscape Digest confirms that AI-enabled attacks have transitioned from experimental nation-state capabilities to routine criminal deployment. The report documents a **single operator compromising nine Mexican government agencies**—including tax records, civil registry data, patient files, and electoral infrastructure—using commercial AI platforms to handle exploitation work.

The attack architecture is worth understanding: the operator ran two AI systems in parallel, one handling live exploitation while the other processed harvested data and fed instructions back. Over **5,000 AI-executed commands** were recovered from attacker-controlled servers. The jailbreak method was elegant rather than forceful—the attacker modified configuration files that AI coding tools load at startup, effectively reprogramming default behavior at the architectural level.

**The EvilTokens Platform**:
The report also details **EvilTokens**, a commercial platform that packages AI attack pipelines into a purchasable product. Buyers receive AI-generated phishing emails written in the target's style, automated financial data extraction from thousands of inboxes, and fake calendar invites timed to create pressure around wire transfers. The sophistication is invisible to the buyer; the social engineering pressure is coordinated automatically.

**Why it matters**:
This is the commoditization of AI-powered attacks. Capabilities that required skilled teams now ship as products. The report notes that AI provider credentials (Anthropic, OpenAI, Groq, Mistral) are being harvested deliberately alongside traditional credentials, giving attackers access to powerful services while appearing to originate from legitimate users.

*Source: [Check Point Research](https://blog.checkpoint.com/research/ai-attacks-are-no-longer-experimental-key-findings-from-the-march-april-2026-ai-threat-landscape)*

### **Microsoft Defender Under Active Exploitation**
Microsoft has disclosed two actively exploited vulnerabilities in Windows Defender. **CVE-2026-45498** (CVSS 4.0) is a denial-of-service bug, while **BlueHammer (CVE-2026-33825)** is a privilege escalation vulnerability. The BlueHammer disclosure is particularly notable: the researcher who discovered it published exploit code after growing exasperated with Microsoft's response timeline.

**Why it matters**:
Windows Defender is ubiquitous across enterprise environments. Actively exploited vulnerabilities in security tools create compounding risk—organizations rely on these tools for protection, making their compromise particularly damaging. The researcher's decision to publish exploit code signals a breakdown in coordinated disclosure norms that may accelerate exploitation.

*Source: [The Hacker News](https://thehackernews.com/2026/05/microsoft-warns-of-two-actively.html)*

## 3. Technical Deep Dives

### **Dirty Frag: New Linux Privilege Escalation Under Exploitation**
Security researchers have disclosed **Dirty Frag and Copy Fail 2**, a chain of two Linux vulnerabilities tracked as **CVE-2026-43284** and **CVE-2026-43500**. The exploit allows an unprivileged user to escalate permissions to root. Discovered by Hyunwoo Kim, the vulnerabilities are possibly already being exploited in attacks.

**The AI Infrastructure Angle**:
Most AI infrastructure runs on Linux. Privilege escalation vulnerabilities in the underlying operating system create pathways for container escapes and host compromise. For organizations running AI workloads on shared infrastructure, kernel-level vulnerabilities represent a fundamental risk that containerization alone cannot mitigate.

**Defensive Actions**:
Organizations should prioritize kernel patching for systems running AI inference or training workloads. The "possibly exploited" designation suggests threat actors are already incorporating this vulnerability into their toolchains.

*Source: [SecurityWeek](https://www.securityweek.com/new-dirty-frag-linux-vulnerability-possibly-exploited-in-attacks/)*

### **Supabase MCP Server: Security Best Practices Emerge**
Supabase has published documentation for its MCP server with explicit security recommendations: don't connect to production databases, don't distribute the server to customers, and ensure development environments contain only non-production or obfuscated data.

**Why this matters**:
This represents a maturation in MCP security thinking. Early MCP implementations often defaulted to broad permissions for convenience. Supabase's approach—treating the MCP server as a development-only tool with restricted access—provides a template for other vendors. The recommendation against giving MCP servers to customers is particularly important; the server operates under developer permissions, making it a potent privilege escalation vector if distributed.

*Source: [Supabase Docs](https://supabase.com/docs/guides/getting-started/mcp)*

### **Quantum-Proofing the Model Context Protocol**
Gopher Security has published guidance on securing MCP deployments against quantum threats using hybrid post-quantum cryptography (PQC). The recommendations focus on **cryptographic agility**—implementing hybrid models that layer NIST-standardized PQC (like ML-KEM) over existing classical encryption.

**The SNDL Threat**:
The concern is **Store Now, Decrypt Later (SNDL)** attacks. MCP frequently transmits highly sensitive, long-lived data like internal strategy documents and source code. Adversaries may be capturing this traffic today to decrypt once quantum capabilities mature. Because MCP acts as a central hub for AI context, it represents a high-value target for such collection.

**Why it matters**:
While quantum computing capable of breaking current encryption remains years away, the transition period for cryptographic infrastructure is measured in decades. Organizations deploying MCP for sensitive workloads should begin planning for PQC migration now.

*Source: [Gopher Security](https://www.gopher.security/blog/securing-model-context-protocol-quantum-proof-cryptography)*

## 4. Community Pulse

### **Anthropic Acquires Stainless for $300M**
Anthropic has acquired **Stainless**, the New York startup whose software generated SDKs for major AI companies including Anthropic, OpenAI, and Google. The deal, valued at approximately $300 million, gives Anthropic control over tooling that competitors rely on.

**The Security Angle**:
SDKs are a critical supply chain component. They handle API authentication, request signing, and error handling—functions that, if compromised, could expose API keys or enable request interception. With Anthropic now owning the SDK generator, competitors may need to audit their SDK supply chains or develop alternatives.

**The Strategic Context**:
This follows Andrej Karpathy's recent move to Anthropic and signals intensifying vertical integration in the AI space. For security teams, the lesson is clear: dependencies on shared infrastructure carry concentration risk.

*Source: [The New Stack](https://thenewstack.io/anthropic-stainless-sdk-acquisition/)*

## 6. Five Things to Take Into the Rest of the Day

1. **Verify Your Agent Skills**: If you're using AI coding agents, implement NVIDIA's verification approach. Check for skill signatures, review skill cards for required permissions, and treat skill installation with the same rigor as npm packages or Python wheels.

2. **Accelerate Your Patch Cycle**: The Project Glasswing data is clear—vulnerabilities are being found faster than ever, but patching remains slow. If your organization can't deploy critical patches within 48 hours, you're operating on a timeline that doesn't match the threat.

3. **Audit AI Configuration Files**: The Check Point report shows attackers are weaponizing agent configuration files as persistent jailbreak vectors. Review `.claude/`, `.cursor/`, and similar directories in your repositories for unauthorized modifications.

4. **Protect AI Provider Credentials**: API keys for Anthropic, OpenAI, and other providers are now primary targets. They enable attackers to operate with your identity and access your data. Rotate these keys monthly and monitor for anomalous usage patterns.

5. **Plan for Post-Quantum Cryptography**: If you're transmitting sensitive data through MCP or similar protocols, begin evaluating hybrid PQC implementations. The SNDL threat means data captured today may be decryptable in the future.
